# ChatGPT R Task Template

1. Run:

```bash
python3 tools/r_render_task.py <target>
```

2. Use the rendered task to create one complete R test file.
3. Follow the global rules in `chatgpt-sources/project-instructions.md`.
4. Follow `chatgpt-sources/r/project-contract.md`.
5. Use `chatgpt-sources/r/example-test-file.R` as the style reference.
