# ChatGPT Rust Task Template

1. Run:

```bash
python3 tools/rust_render_task.py <target>
```

2. Use the rendered task to create one complete Rust test file.
3. Follow the global rules in `chatgpt-sources/project-instructions.md`.
4. Follow `chatgpt-sources/rust/project-contract.md`.
5. Use `chatgpt-sources/rust/example-test-file.rs` as the style reference.
